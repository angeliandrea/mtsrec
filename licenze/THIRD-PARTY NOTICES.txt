FFmpeg
  libavcodec, libavformat and libavutil, version 9.0.2, built from the official source release
  (https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz) with only the parts the recorder uses: DNxHD, MJPEG
  and PCM codecs, MOV and WAV formats, file protocol. No GPL or non-free parts are enabled.
  Licensed under the GNU Lesser General Public License, version 2.1 or later: see "FFmpeg LICENSE.txt".
  The libraries are linked statically into mtsrec.exe. The complete source code of the recorder and the
  scripts that build FFmpeg and link it (ffmpeg\compila-ffmpeg.sh and .bat, CMakeLists.txt) are published
  at https://github.com/angeliandrea/mtsrec, so the program can be rebuilt with a modified FFmpeg.
  FFmpeg is a trademark of Fabrice Bellard.

Python
  Python 3.13 embeddable package, from python.org, in the "python" folder.
  Licensed under the Python Software Foundation License: see "python\LICENSE.txt".

Microsoft Edge WebView2
  The program window uses the WebView2 Runtime already present in Windows, through the static loader of
  the Microsoft WebView2 SDK. See "WebView2 LICENSE.txt".
